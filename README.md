# Neutron - QuarkReader

Each story is referred to a 'Quark'; this is read by the voice assistant.

This project is a pure python based project which uses tkinter, pygame and pyttsx3 to mimic a basic audiobook app. 
It uses tkinter for generating windows, pygame to pause and play the reader and pyttsx3 to initialise a voice assistant reader to read the stories.
It also lets you write a custom story and read it out for you.

- Run the main.py file under the Assets folder
